# Story 37: Create Templates for Testing

**GitHub Issue:** [#37](https://github.com/apkasten906/resume-builder-9000/issues/37)
**Author:** apkasten906
**Created:** 2025-10-02

## Story

As a user working with GitHub CoPilot, I want templates for the various kinds of tests in the solution, so that I can simplify the process of creating new tests and so that pair programming with GitHub copilot is consistent and has some clearer guidelines that lead to simpler, more maintainable code.

## Acceptance Criteria

- Each type of test has a template - unit, integration, e2e
- Each template uses a common setup and teardown process
- Each template uses the same process for resolving host address
- Each template uses the same method of logging
- Each template uses the same method of authentication (if needed)
